# HazMat Ops Study Hub

Study site for HazMat Operations (Chapters 29–36, Core Knowledge Review, Study Guide objectives 1–38 and recognition plates).

Features: quick study sheet, full searchable guide, flashcards, adaptive learn mode, custom practice exams, games (Match, Speed ID, True/False Blitz, Survival), recognition plate gallery, answer keys, and your own cards/questions.

It is a single static `index.html` with no build step. Progress is saved in your browser.
